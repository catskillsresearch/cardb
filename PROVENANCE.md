# Provenance

This repository is the substantive development of the CARDB formalization
(the number of topological bases of a finite set). It is not a thin wrapper
and not a reimplementation of an independent formalization.

The work began as a subdirectory of
[`catskillsresearch/scott_models`](https://github.com/catskillsresearch/scott_models)
at `CARDB/`. That parent repository is about Scott models and related
constructions. CARDB was parked there because it was convenient, not because
it belongs to that project. The first commit of this repository
(`a4d3fc0`) is the split.

This repository is the continuation of that directory: same author, same
license (Apache-2.0), same Lean development, moved to its own Lake package
so the statement of record and Palomar metadata live here. The old path is
historical only. Further work belongs in
[`catskillsresearch/cardb`](https://github.com/catskillsresearch/cardb).

This formalization is registered in the Palomar registry as
[PALOMAR-2026-08-20-000003](https://palomar-registry.org/entry?id=PALOMAR-2026-08-20-000003&version=1)
(version 1). Palomar preserves a pinned commit of *this* repository. It does
not archive `scott_models`.
